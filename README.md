# Aurelia Luxury Estates — أوريليا للعقارات الفاخرة

Arabic-first luxury real-estate platform for Riyadh, Dubai, New Cairo and the North Coast.

**Live demo:** https://aurelia-realty.surge.sh

![Aurelia Luxury Estates — أوريليا للعقارات الفاخرة screenshot](docs/screenshot.webp)

## Features

- Buy / rent search with city and property-type filters
- Side-by-side property comparison
- Mortgage & installment payment calculator
- Book an in-person viewing or a 3D video tour
- Advisors directory and ROI advisory
- Arabic (RTL) and English (LTR) interface

## Tech stack

React 19 · Vite · CSS

## Run it locally

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```
